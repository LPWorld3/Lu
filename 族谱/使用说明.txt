族谱网页 使用说明
==================

一、文件夹内容
- 族谱网页.html   主页面（双击用浏览器打开即可使用）
- 初始数据.json   第一世初始数据（与网页内置数据一致，仅作存档参考）
- 使用说明.txt    本文件
- 族谱数据_*.json 您通过网页"备份数据"按钮导出的完整数据文件（含所有录入内容），请定期备份到这个文件夹

二、日常使用
1. 双击打开 族谱网页.html
2. 点占位节点"长子（待录）"等 → 弹出录入框，填姓名/性别/配偶/备注 → 保存，节点自动转实线
3. 人物名字后方自动显示"（子几 女几）"，完全根据已填写的内容统计（只读、不可手动调整），
   添加/删除成员后自动变化；长子始终排在最右
4. 点人物名字 → 直接查询其完整信息；顶部"查询"按钮可按名搜索
5. 手机打开会自动弹出菜单：查询 / 添加 / 备份数据 / 恢复数据
6. 卡片右上角有"编辑"按钮 → 可修改姓名/配偶/备注/性别/生卒，也可修改所属世代和父亲；
   选定父亲后，所属世代自动对齐为父亲下一世；改父亲时自动从旧父亲名下摘除、挂到新父亲名下（不重复）；
   改世代时本人连同已录名的后代整支随迁；不能把父亲设为自己或自己的后代（成环会被拦截）；
   改名后父系子嗣条目自动同步。
7. 几子几女为只读统计：完全按已填写的子嗣内容计算（未填写的"待录"占位不计入），
   卡片与查询结果中自动更新，没有手动调整数量的入口。
   添加成员时可选性别：默认男，可选女；女性按内容计入"女几"，
   默认不上树（"女性名字"开关打开后，已录名的女性才显示在树上）。
8. 生卒时间：添加/编辑弹窗中填"出生 / 逝世"（如 1890 / 清光绪三年），卡片与查询结果会显示。
8b. 继子（过继）：添加/编辑弹窗中勾选"继子（过继）"，父子连线上会显示「继子」标注；
    取消勾选即移除；查询结果同样显示。
8c. 子的数量：编辑人物时弹窗中有"子的数量 － N ＋"步进器，直接加减数字；
    继子/未录名者计入数字（卡片显示 子N），但不在树上生成节点；
    数量不能减到低于已录名的子数；旧数据无此字段时默认等于录名子数。
9. 显示样式：全部内容靠右对齐（谱牒式）；"第X世"标签悬浮在树视口右上角，随滚动自动切换当前世代；
   右侧世代导航常驻不变。排序从右往左，最右侧为最大（长子在最右，依次往左）；
   点"待录"占位录入时精确绑定到该槽位。
10. 兄弟排序：兄弟长幼顺序以父亲"子嗣"列表的先后为准（第一个=长子=显示在最右）。
    通过弹窗添加的新成员一律排在最末（最幼=显示在最左），不会插到兄长前面；
    若历史数据顺序不对，编辑弹窗中有"兄弟排序"按钮：→右移（更年长）/ ←左移（更年幼），
    点一下立即生效，可把长子调回最右。

三、数据备份（重要）
您在网页里录入的所有内容都保存在浏览器本地。为避免丢失：
- 点"备份数据"：首次使用会弹出一次保存位置选择，请选到本工作文件夹（如"族谱数据备份.json"）；
  之后每次备份都会**自动写入同一个文件，不再弹出任何另存框**，页面底部有提示条确认。
- 绑定备份文件后，每次在网页里改动数据（添加/编辑/删除）约 1.5 秒后也会**静默自动备份**到该文件。
- 若浏览器不支持自动写入（如部分手机浏览器），则退回普通下载方式。
- 换电脑或数据丢失时：打开网页 → 点"恢复数据" → 选择之前备份的 json 文件即可全部还原。
- 想换备份文件位置：无法在页面里解绑；清空浏览器该站点数据（IndexedDB"zupu_fs"）后重新点
  "备份数据"即可重新选择。

四、直接在数据文件里批量补充世代（可选）
打开备份出的 json 文件（或初始数据.json），按结构添加：
{
  "generations": [
    { "title": "第一世", "people": [ { "givenName": "世昌", "spouse": "赵氏", "note": "",
        "sons": [ { "givenName": "", "sex": "m" }, ... ] } ] },
    { "title": "第二世", "people": [ { "givenName": "长子名", "spouse": "配某氏", "note": "", "sons": [] } ] }
  ]
}
说明：
- givenName 只填名（不填姓），页面自动不显示姓氏
- sex：'m' 男 / 'f' 女，决定"长子/长女"称谓与"几子几女"统计
- sons 里 givenName 留空 = 占位（显示"待录"，点击可录入）
- introText 填入一段介绍文字后，页面顶部预留位置会自动显示
- 修改后保存文件 → 网页"恢复数据"选择该文件即可
